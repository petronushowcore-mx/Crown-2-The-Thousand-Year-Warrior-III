# Warrior III: Lean companion

C2.lean formalises the mixed-fibre criterion and the declared finite seam and open-future examples. It does not establish a universal prohibition on reading from snapshots, a result about every shell of The Crown, or a physical identity mechanism.

compilation-record.json records the earlier compilation of these exact bytes, with the pinned toolchain and Mathlib revision. Packaging did not rerun compilation. The source currently imports Std; the shared Lake environment also pins Mathlib for consistency with its recorded compilation.

With elan installed, run from this directory. Initial dependency retrieval requires network access.

```sh
lake update
lake exe cache get
lake env lean C2.lean
```

Lean checks the formal proofs; correspondence between each formal statement and the manuscript remains a separate mathematical obligation.
